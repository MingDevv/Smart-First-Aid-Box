# ESP32 firmware

Open **`esp32_smart_box/esp32_smart_box.ino`** in Arduino IDE, or compile the
`esp32_smart_box` directory with Arduino CLI. This is the only sketch.

The former `.ino` in this directory was removed because Arduino requires a
matching sketch-directory name. Its source remains in Git history.

Configuration, paired micro:bit update, UART wiring and physical acceptance:
[Pi local setup](../docs/PI_LOCAL_SETUP.md).
