# fonts/ — ฟอนต์ที่โฮสต์เอง สำหรับหน้าตู้ (kiosk)

หน้าตู้บน Raspberry Pi ต้องอ่านออกแม้ **ไม่มีอินเทอร์เน็ต** ไฟล์ในโฟลเดอร์นี้จึงถูกเก็บไว้ในเรพ
ไม่ได้โหลดจาก `fonts.googleapis.com` เหมือนหน้าเว็บอื่น

## ทำไมต้องมี

หน้าเว็บเดิมโหลดฟอนต์และไอคอนจาก Google Fonts ทั้งหมด:

- `fonts.googleapis.com/css2?family=Anuphan&family=IBM+Plex+Mono&family=IBM+Plex+Sans+Thai`
- `fonts.googleapis.com/css2?family=Material+Symbols+Rounded`

ถ้าเน็ตนอกล่ม สองอย่างนี้พังพร้อมกัน:

1. ตัวหนังสือไทยตกไปใช้ฟอนต์ระบบ — ขนาดและความสูงบรรทัดเปลี่ยน ปุ่มที่วัดไว้กับจอ 800×480 ล้น
2. **ไอคอน Material Symbols แสดงเป็นคำภาษาอังกฤษ** เพราะเป็นฟอนต์ ligature — `chevron_right`
   จะขึ้นเป็นตัวอักษร 13 ตัวกลางปุ่ม ไม่ใช่ลูกศร

หน้าตู้จึงแก้สองทาง: ฟอนต์ไทยโฮสต์เอง (โฟลเดอร์นี้) และ **ไอคอนเป็น inline SVG ไม่ใช้ฟอนต์ไอคอนเลย**

## ไฟล์

`ibm-plex-sans-thai-{400,500,600}-{thai,latin}.woff2` — subset ตรงตามที่ Google Fonts ตัดให้
(`U+0E01-0E5B` สำหรับไทย, `U+0000-00FF` สำหรับละติน) รวม 6 ไฟล์ ~84 KB

ดึงเมื่อ 2026-09-11 จาก `fonts.gstatic.com` เวอร์ชัน `v11` ของตระกูล `ibmplexsansthai`

ต้นทาง <https://github.com/IBM/plex> · โฮสต์ซ้ำได้ตาม OFL โดยไม่ต้องเปลี่ยนชื่อฟอนต์
ตราบใดที่ไม่ได้ขายแยกและไม่ได้แก้ไขตัวฟอนต์ — ไฟล์ชุดนี้ไม่ได้ถูกแก้ไข

## เปลี่ยนเวอร์ชันอย่างไร

อย่าแก้ไฟล์ `.woff2` ตรงๆ ถ้าจะอัปเวอร์ชันให้ดึงใหม่ทั้งชุดแล้วแก้ `@font-face` ใน `css/kiosk.css`
ให้ตรงกัน — ชื่อไฟล์ผูกกับน้ำหนักและ subset ไม่ผูกกับ hash ของ Google
